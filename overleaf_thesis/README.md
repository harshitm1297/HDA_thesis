# Overleaf thesis project

This directory is a portable LaTeX version of `../THESIS_REPORT.md`. It follows a broadly European academic thesis structure using A4 KOMA-Script typography, British English, author–year citations, lists of figures and tables, explicit data-protection and IVDR boundaries, and separate appendices.

## Upload to Overleaf

1. Upload the complete contents of this directory as a new Overleaf project. A ZIP may be created locally when required, but generated archives are not versioned.
2. Set `main.tex` as the main document.
3. Use the pdfLaTeX compiler. Overleaf will run Biber for the bibliography.
4. Replace the bracketed fields in `metadata.tex` and the declaration/acknowledgements placeholders.
5. Apply any mandatory university cover page, declaration wording, logo, margins or citation style before submission.

## Project layout

- `main.tex`: document class, typography, front matter and chapter order.
- `metadata.tex`: candidate and institutional metadata.
- `frontmatter/`: declaration, acknowledgements, abstract and abbreviations.
- `chapters/`: ten numbered thesis chapters.
- `appendices/`: artifact inventory, reporting status and frozen configuration summary.
- `figures/`: the 15 reproducible figures generated by Phases 1–7.
- `references.bib`: BibLaTeX/Biber bibliography restricted to the declared methodological evidence base.
- `../THESIS_REPORT.md`: canonical Markdown manuscript retained at the repository root for traceability.

The project deliberately records Phase 2 as unimplemented and external validation as not executed. Compilation success does not change those scientific limitations.

## Validation status

The generator verified all 16 `\\input` targets, all 15 figure files, all 25 citation keys, balanced LaTeX environments, unique labels and the absence of raw Markdown constructs. The project was then compiled locally with MiKTeX using the standard pdfLaTeX--Biber--pdfLaTeX sequence. The 76-page A4 render was rasterised and visually reviewed after repairing long-table and long-identifier wrapping. Rendered PDFs are intentionally excluded from version control.
